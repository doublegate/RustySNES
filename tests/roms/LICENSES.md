# Test-ROM and test-vector licences

The authoritative inventory of every test artefact **committed** to this repository, with its
licence and the notice-preservation obligation that comes with it. `NOTICE` §6 points here.

> **No commercial ROM is committed to this repository, ever.** Commercial dumps and coprocessor
> firmware used for local validation live under `tests/roms/external/`, which is **gitignored**
> (`.gitignore:93`) and never distributed. Only *derived* artefacts — screenshots and hashes — are
> ever committed from them. Suites that need those dumps self-skip when they are absent, so a clean
> checkout builds and tests green without them.

**Every count below was produced with `git ls-files`, not `find`.** That distinction matters: an
on-disk walk also picks up the gitignored `external/` tree and any untracked scratch, and would
overcount. Each command is given so the number can be re-derived rather than trusted.

```bash
git ls-files 'tests/roms/**' | wc -l          # 347 committed files in total
git ls-files 'tests/roms/**' | grep -c '\.sfc$'   # 36 committed .sfc images
```

Every corpus directory carries its own `LICENSE` file precisely because MIT and zlib both require
their notice to be preserved in redistribution. Nothing here relies on this file alone.

### `AccuracySNES/` — first-party

RustySNES's own self-scoring accuracy cartridge, generated by `accuracysnes-gen` from committed
65816 sources. Four images are committed under `build/`:

```text
accuracysnes.sfc          NTSC LoROM (the primary battery image)
accuracysnes-pal.sfc      PAL — differs from the above by ONE header byte plus checksum
accuracysnes-hirom.sfc    HiROM mapping variant
accuracysnes-exhirom.sfc  ExHiROM mapping variant
```

Dual-licensed MIT OR Apache-2.0 with the rest of the project. It is *our* test ROM; it carries no
third-party content, and it is the reason this project can claim on-cart accuracy results that mean
the same thing on any emulator.

### `undisbeliever/` — Marcus Rowe

29 `.sfc` PPU/HDMA/DMA timing ROMs (the `hdma-*`, `hdmaen_latch_*`, `inidisp_*` families and
others). **Two licence files are committed, and both are needed** — the ROMs here were taken under
MIT, while the upstream repository has since moved to zlib:

- `LICENSE` — The MIT License (MIT), (c) 2019 Marcus Rowe
- `LICENSE.zlib-repo-current` — zlib, (c) 2016 Marcus Rowe

Keeping both is deliberate: dropping the MIT text because upstream relicensed would remove the
notice that actually governs the copies committed here.

### `gilyon/` — 65816 and SPC700 instruction tests

`cputest-basic.sfc`, `cputest-full.sfc`, `spctest.sfc`, plus the expected-result manifests
(`tests-*.txt`) the harness decodes. MIT, (c) 2023 gilyon.

### `spc700-singlestep/` — SingleStepTests per-opcode vectors

A **deterministically sampled subset** of the [SingleStepTests/spc700](https://github.com/SingleStepTests/spc700)
per-opcode JSON oracle (TomHarte `ProcessorTests` format), MIT, (c) 2024 SingleStepTests.

256 files (one per opcode) are committed. The full upstream set is 256 opcodes x 1000 tests
(~80 MB), which is too large for a source tree; the sampling rule is documented and reproducible in
`SAMPLING.md`, and the complete set is kept locally under the gitignored
`tests/roms/external/spc700-singlestep-full/` for exhaustive runs.

**On oracle provenance:** SingleStepTests is not treated as ground truth where it disagrees with
SNES hardware. This project's recorded position is that it is the *outlier* on several 65816/SPC700
quirks, and RustySNES matches ares / bsnes / MesenCE / snes9x and its own AccuracySNES battery
instead. See `docs/rom-test-corpus.md`.

## Not committed, and why

| Category | Where it lives | Why not committed |
|---|---|---|
| Commercial ROM dumps | `tests/roms/external/` (gitignored) | Copyrighted. Never distributed. |
| Coprocessor firmware (DSP-1, CX4, ST018, ...) | `tests/roms/external/` (gitignored) | Copyrighted chip ROMs; user-supplied only (`docs/adr/0003`). |
| The full SingleStepTests set | `tests/roms/external/spc700-singlestep-full/` | ~80 MB; sampled subset committed instead. |
| SNESdev-wiki homebrew ROMs | local only | Unlicensed — no licence grant to redistribute, so not committable even though freely downloadable. |

That last row is worth stating plainly: "freely available" is not a licence. A ROM with no licence
statement cannot be redistributed here regardless of how easy it is to obtain, which is why the
corpus is smaller than the set of ROMs this project is actually tested against.
